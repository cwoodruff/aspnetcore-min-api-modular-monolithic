# ASP.NET Core Minimal API Workshop

## Build Production-Ready APIs with Modular Monolithic Architecture

**Full-Day Hands-On Training**

---

### The Smart Path to Scalable APIs

Skip the microservices complexity. Learn the architecture pattern that gives you clean module boundaries, easy team scaling, and a clear path to microservices—when you actually need them.

---

### In One Day, You'll Build:

- **Modular API** with 5 independent modules using the IModule contract
- **JWT Authentication** with RS256 signing and refresh token rotation
- **Policy-Based Authorization** with multi-tenant support
- **Service Layer** with caching and FluentValidation
- **Rate Limiting** to protect your API from abuse
- **Integration Tests** using WebApplicationFactory

---

### You'll Learn:

| Architecture | Security | Performance |
|-------------|----------|-------------|
| Module composition | JWT Bearer auth | Repository pattern |
| Clean boundaries | Authorization policies | Cache-aside pattern |
| Service layer patterns | Rate limiting | Tag-based invalidation |
